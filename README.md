## About the Project 

This project aims to provide highly relevant movie recommendations by leveraging two powerful approaches:

1.  **Content-Based Filtering**: Recommends movies similar to those a user has liked in the past, based on movie attributes like title and genres.
2.  **Collaborative Filtering**: Recommends movies that users with similar tastes have liked.

The system integrates these methods into a hybrid model to offer a more robust and accurate recommendation experience. A Flask backend serves these recommendations via a RESTful API, and a simple HTML/CSS/JavaScript frontend provides an interactive user interface.

The project utilizes the MovieLens dataset (`ml-latest-small`) for its movie and rating information. 

## Features 

*   **Hybrid Recommendation Engine**: Combines content-based and collaborative filtering for enhanced accuracy.
*   **Content-Based Filtering**: Utilizes TF-IDF vectorization and cosine similarity on movie features (title, genres).
*   **Collaborative Filtering**: Employs user-user similarity based on rating patterns.
*   **Flask REST API**: Exposes recommendation functionalities through well-defined API endpoints.
*   **Movie Search Functionality**: Allows users to search for movies to get recommendations.
*   **Interactive Frontend**: A simple web interface for searching movies and receiving recommendations.
*   **Data Preprocessing**: Includes scripts for cleaning and preparing the MovieLens dataset.
*   **Model Evaluation**: Implements scripts to evaluate recommendation model performance (RMSE, MAE, Precision, Recall).

    The project primarily relies on `pandas`, `scikit-learn`, and `flask`. You can install them using pip:

3.  **Prepare the Data**:
    The necessary `processed_movies.csv` and `processed_ratings.csv` files should be generated by the preprocessing scripts. If they are not present, you can run the preprocessing steps:
    *   Run `data_collection_ml.py` to understand the raw data.

## Usage 

This project serves as a recommendation engine that can be accessed via its Flask API and a simple frontend.

1.  **Run the Flask Application**:
    Navigate to the project directory and run the main application file:
    ```bash
    python app.py
    ```
    The server will start, and a browser window should automatically open at `http://127.0.0.1:5000/`.

2.  **Interact with the Frontend**:
    *   **Search for a Movie**: Enter a movie title in the search bar and click `Search`. Select a movie from the results.
    *   **Get Recommendations**: After selecting a movie, enter a `User ID` (e.g., `1`) and click `Recommend Movies`.
    *   The system will display a list of recommended movies based on the hybrid model.

## How to Use 

This recommendation system can be integrated into various applications:

*   **Personalized Content Discovery**: Enhance user experience on streaming platforms by suggesting movies tailored to individual preferences.
*   **E-commerce Recommendations**: Adapt the logic to recommend products based on user purchase history and product similarities.
*   **Content Curation**: Help users discover new content they might enjoy, increasing engagement and satisfaction.

**Example Workflow:**

1.  A user searches for "Inception".
2.  The system retrieves similar movies based on content (e.g., other sci-fi thrillers).
3.  The system identifies users who liked "Inception" and have similar viewing habits.
4.  It then recommends movies liked by those similar users but not yet seen by the current user.
5.  Both content and collaborative scores are combined to provide a final hybrid score, ranking the recommendations.

## API Reference 

The Flask application exposes the following API endpoints:

*   **`GET /`**
    *   Serves the main frontend application (`frontend/index.html`).

*   **`GET /<path:filename>`**
    *   Serves static files (CSS, JS) from the `frontend` directory.

*   **`GET /search`**
    *   **Query Parameters**: `q` (string, search query)
    *   **Returns**: A JSON array of movie objects matching the query, each with `movieId`, `title`, and `genres`.
    *   Example: `/search?q=Toy%20Story`

*   **`GET /movie/<int:movie_id>`**
    *   **Path Parameter**: `movie_id` (integer, the ID of the movie)
    *   **Returns**: A JSON object with details of the specified movie (`movieId`, `title`, `genres`).
    *   Example: `/movie/1`

*   **`GET /recommend`**
    *   **Query Parameters**: 
        *   `movie` (string, the title of the movie to base recommendations on)
        *   `user_id` (integer, the ID of the user)
        *   `top_n` (integer, optional, number of recommendations to return, default is 10)
    *   **Returns**: A JSON object containing the status, input movie, user ID, and an array of `recommendations`. Each recommendation includes `movieId`, `title`, `genres`, `content_score`, `collaborative_score`, and `hybrid_score`.
    *   Example: `/recommend?movie=Toy%20Story%20(1995)&user_id=1&top_n=5`
